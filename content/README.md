# Content

Reviewed exercise demonstrations, workout templates and the tips library.

Structure (target: 60 reviewed exercises, 12 editable templates — §5):

- `exercises/` — one JSON per `ExerciseDefinition`, plus media references
- `templates/` — `WorkoutTemplate` JSON
- `tips/` — tips with author/reviewer, last-reviewed date, topic, audience exclusions (§22)
- `LICENSES.md` — every media asset's licence; placeholders marked

Nothing here may contain personal data. Public content is bundled or hosted
separately from any user data path.
